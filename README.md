## Запуск

1. Клонировать репозиторий
2. Перейти в папку проекта
3. Выполнить `flutter pub get`
4. Запустить командой `flutter run -d chrome`

что изучили

- создание веб-страницы
- запуск дебаг модуля
- горячие перезагрузки
- выбор запуска платформы
